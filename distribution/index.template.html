Installer MasterZone

  1. Android : ouvrez cette page dans votre navigateur et choisissez la version téléphone / tablette.
  2. Ouvrez le fichier APK téléchargé. Si Android le demande, autorisez temporairement l’installation depuis ce navigateur ou le gestionnaire de fichiers, puis appuyez sur Installer.
  3. Android TV / Google TV : ouvrez cette page avec Downloader ou un navigateur TV, choisissez la version TV puis installez le fichier APK. Autorisez cette source d’installation si Android le demande.
  4. Lancez MasterZone puis choisissez Ajouter une source. Utilisez uniquement les accès que vous êtes autorisé à consulter.

Aucun bouquet ni identifiant fournisseur n’est inclus. Une mise à jour exige le certificat de signature d’origine. Les codecs et la lecture dépendent de l’appareil et de la source.
